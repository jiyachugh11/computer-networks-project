# TrafficCLIP

TrafficCLIP is a network traffic classification project based on visual and semantic representations of network traffic.

## Project Structure

- `data/` - Dataset and processed traffic images
- `src/preprocessing/` - PCAP preprocessing
- `src/datasets/` - Dataset loading
- `src/models/` - TrafficCLIP model components
- `src/losses/` - Training losses
- `src/training/` - Training utilities
- `src/utils/` - Evaluation and visualization utilities
- `configs/` - Configuration files
- `checkpoints/` - Saved model checkpoints
- `outputs/` - Experiment outputs
